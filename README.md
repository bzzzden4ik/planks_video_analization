# Подсчёт и измерение досок на видео конвейера

Это решение без нейросети (классическое компьютерное зрение).
Все команды выполняются в PowerShell **из папки `analization`**:

```powershell
cd C:\Users\user\Documents\Projects\pyProjects\MLKsusha\analization
```

## 1. Установка (один раз)

```powershell
C:\Python312\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`.venv` — отдельное окружение проекта, библиотеки ставятся только туда.

## 2. Настройки — `config.toml`

| Параметр | Что это |
|---|---|
| `video.path` | путь к видео |
| `marker.length_cm`, `marker.width_cm` | размеры маркера (планка под лестницей) |
| `boards.normal_length_cm` | N — длина нормальной доски, см (сейчас 1000) |
| `boards.tolerance_percent` | доска — выброс, если длина ≤ N × (1 − процент/100) |

Проверить настройки: `.venv\Scripts\python.exe config.py`

## 3. Основной запуск

```powershell
.venv\Scripts\python.exe process_video.py
```

Результаты в папке `results/`:
- `annotated.mp4` — видео с разметкой: контур доски, торцы, длина, счётчик;
- `boards.csv` — таблица досок (открывается в Excel, разделитель `;`).

Полезные варианты:
```powershell
.venv\Scripts\python.exe process_video.py --start 75 --end 350   # только часть видео (секунды)
.venv\Scripts\python.exe process_video.py --no-video             # только CSV, быстрее
```

### Как читать видео
- **Зелёный контур** — текущая доска; **красный** — текущая доска-выброс; **серый** — прошлая доска, уходящая в станок.
- **Жёлтая точка** на торце — торец найден и использован для измерения.
- **Оранжевый круг** — торец не виден (за краем кадра или закрыт рабочим).
- Панель слева сверху — время, число досок, нормальные / выбросы / не измеренные.

## Как измеряется длина

На этом видео оба торца доски почти никогда не видны одновременно: при укладке
правый конец за краем кадра, а левый — у рабочего и входа в станок; когда правый торец
появляется, левый уже в станке. Поэтому:

1. При укладке левый торец стоит у входа в станок (x = 73 пикс; проверено на 1-й доске).
2. Программа следит, на сколько сантиметров сдвинулась доска (D) — сравнивает рисунок
   центральной части доски от кадра к кадру.
3. Когда правый торец появляется в надёжной зоне кадра:
   `длина = s(правый торец) + |D| − s(вход в станок)`.
4. Доска — выброс, если длина ≤ N × (1 − погрешность/100); N задаётся в config.toml.

## Точность и ограничения (важно)

- Первая доска: автоматически 986 см, полуручная проверка 991 см (разница 0,5%).
- Остальные доски: 899–987 см, разброс около ±4% — укладывается в требуемые ±10%.
- **Допущение:** каждую доску при укладке кладут левым торцом к входу в станок.
  Если доску положат дальше от станка, длина получится завышенной на это расстояние.
- Камера с «рыбьим глазом»: у краёв кадра масштаб сжат в 2–3 раза.
- Для точности ±10 см (а не ±10%) нужна другая установка камеры: чтобы оба торца
  были видны одновременно.
